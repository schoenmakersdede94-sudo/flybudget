# FlyBudget

Persoonlijke budgettracker gebouwd met React, TypeScript, Vite en Tailwind CSS.

## Features

- Dashboard met inkomen, uitgaven, balans en besparingen
- Transacties toevoegen en verwijderen per categorie
- Taartdiagram voor uitgaven per categorie
- Maandnavigatie
- Lokale opslag in de browser (localStorage)
- Dark mode support

## Ontwikkeling

```bash
npm install
npm run dev
```

## Deployment

Automatisch via GitHub Actions naar GitHub Pages bij elke push naar `main`.
